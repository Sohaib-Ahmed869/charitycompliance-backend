Cost per tenant — falls, then settles near A$34

Monthly cost to serve one charity at each band. It drops, then levels off — it does not fall to near-zero.

The per-tenant cost is an average — it varies

A$34 is a blended figure. The real cost of a charity depends on:

Size of the organisation
More staff and board users means more accounts, documents and activity. A small charity (5–10 users) costs far less than a large one (100+ users).
Incoming traffic & activity
Frequent logins, report generation, file uploads and downloads all consume server time and data — a busy charity costs more than a quiet one.

In practice a light, small charity may cost around A$20/month, while a large, highly active organisation can run A$70–90/month. A$34 is the typical blended average across a mixed customer base.

Recommended server size

The backend runs the API, live updates (websockets) and PDF generation with a headless browser. PDF generation is the heaviest task — each report briefly uses a full processor core and several hundred MB of memory. The server is sized around that.
